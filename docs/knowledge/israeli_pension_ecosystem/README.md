# Israeli Pension Ecosystem — Discovery Knowledge

*Goose Financial — Discovery Knowledge*

*Version 0.1 — Draft, researched 2026-07-23*

This directory holds ecosystem-first research. It is deliberately **not** an approved Canonical Knowledge Object or a calculation specification. It records what the current source set supports, what it merely suggests, and what remains unknown before implementation.

## Contents

- [`ECOSYSTEM_FOUNDATION_DISCOVERY.md`](ECOSYSTEM_FOUNDATION_DISCOVERY.md) (`IPE-FOUNDATION-DISCOVERY`) — purpose, product-neutral conceptual hierarchy, historical guardrails, evidence register, candidate canonical model, and research backlog.

## Status and use

The artifact is a durable discovery baseline. A later, approved modeling milestone may split stable individual rules into Canonical Knowledge Objects. It must not be used to compute an entitlement, tax outcome, contribution obligation, or withdrawal right without retrieving the rule applicable to the relevant dates and facts.
